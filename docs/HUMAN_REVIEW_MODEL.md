# HUMAN REVIEW MODEL & AI RESULT SEPARATION

**Architecture Principle**: Immutable AI Predictions & Decoupled Human Audit  
**Date**: September 4, 2026  

---

## 1. Core Principle: Immutable AI Inference

In S.P.O.T., computer vision predictions generated by a `VisionModel` are **IMMUTABLE AUDIT ARTIFACTS**. A human reviewer or APMC agricultural inspector must **NEVER** overwrite, mutate, or erase raw AI predictions in the database or reporting contracts.

Instead, the system enforces a 3-layer decoupled decision model:

```
┌────────────────────────────────────────────────────────┐
│ 1. AI_RESULT                                           │
│ Raw VisionResult + Automated GradingPolicy Evaluation   │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│ 2. HUMAN_REVIEW (Optional Audit Event)                 │
│ Inspector review_status, review_reasons, notes, ID    │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│ 3. FINAL_DECISION                                      │
│ Effective lot grade (Defaults to AI_RESULT if no human │
│ override; reflects inspector override if reviewed)     │
└────────────────────────────────────────────────────────┘
```

---

## 2. Review Trigger Workflow (`REVIEW_REQUIRED`)

The automated pipeline flags an inspection for human review (`review_status = "REVIEW_REQUIRED"`) under specific objective triggers:

1. **Pipeline Confidence Gate**: Automated overall confidence score drops below policy threshold (e.g. `< 0.75`).
2. **Quality Gate Marginality**: Quality screening metrics fall near borderline limits.
3. **Dispute Resolution Request**: Supplier or APMC buyer submits a formal procurement dispute.

---

## 3. Review Object Schema

```json
{
  "review_status": "REVIEW_REQUIRED",
  "review_reason": [
    "Inspection flagged for human review: low inspection confidence (0.68 < 0.75)"
  ],
  "triggered_by": "PIPELINE_CONFIDENCE_GATE",
  "created_at": "2026-09-04T11:00:00Z",
  "human_review_event": null
}
```

If a human review event occurs:

```json
{
  "human_review_event": {
    "review_event_id": "REV-2026-0042",
    "reviewer_id": "INSPECTOR-APMC-77",
    "reviewer_role": "LICENSED_APMC_GRADOR",
    "action": "OVERRIDE_GRADE",
    "ai_grade": "Grade-URS",
    "final_assigned_grade": "Grade-A",
    "notes": "Bulb size visual inspection confirmed 48mm diameter across sample.",
    "reviewed_at": "2026-09-04T11:15:00Z"
  }
}
```

This guarantees complete traceability and prevents silent manipulation of AI performance metrics.
